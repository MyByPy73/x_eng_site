# X Engenharia — Site institucional

Landing page de uma página para a X Engenharia, pronta para publicação no GitHub Pages.

## Arquivos

- `index.html` — estrutura da página
- `style.css` — identidade visual e responsividade
- `script.js` — menu mobile e pequenos comportamentos

## Publicação no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie os três arquivos para a raiz do repositório.
3. Vá em **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`.
6. Salve.

Depois, em **Custom domain**, informe seu domínio `.com.br`.

## Antes de publicar

Os textos e dados de contato foram montados a partir do cartão CNPJ fornecido. Recomenda-se revisar:
- telefone;
- e-mail;
- endereço;
- descrição comercial dos serviços;
- eventual número de CREA/registro profissional;
- imagens e portfólio, se houver.

O site não afirma possuir certificações, obras ou portfólio que não constem no material fornecido.
